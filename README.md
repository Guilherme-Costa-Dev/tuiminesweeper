## Install
With go installed:
```
go install github.com/Guilherme-Costa-Dev/tuiminesweeper@latest
```
Make sure you have your path set up right so you can run it with:
```
tuiminesweeper
```

## Build from source
```
git clone github.com/Guilherme-Costa-Dev/tuiminesweeper
go build -o tuiminesweeper
./tuiminesweeper
```

## Usage
- Flag **-size**: Defines the width and height of the board (defaults to 30)
- Flag **-mines**: Defines how much mines you want (defaults to 120)
